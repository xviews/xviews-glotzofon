Kurz was zeigen, ohne Gedöns.

Nervt es dich auch? Du willst deinen Freunden nur kurz etwas auf deinem Bildschirm zeigen, und plötzlich muss jeder erst ein Fernwartungsprogramm installieren, ein Konto anlegen oder in einen Call einsteigen.

Mit Glotzofon: EXE starten, Code weitergeben, fertig. Deine Freunde schauen in der App oder einfach hier im Browser zu. Nur zuschauen, keine Fernsteuerung.

Code bekommen?

Am besten in Chrome, Edge oder Firefox am PC. Das Bild läuft direkt und verschlüsselt vom anderen PC zu dir.

So geht's

Drei Schritte, keine halbe Stunde Einrichtung.

1

Starten

XviewsGlotzofon.exe öffnen und auf „Bildschirm teilen“ klicken. Ganzen Bildschirm oder nur ein Fenster wählen.

2

Code rüber

Glotzofon zeigt einen Code wie K7M-X4P und kopiert ihn gleich. Per Messenger weitergeben, fertig.

3

Glotze an

Deine Freunde tippen den Code in der App oder hier auf der Seite ein und schauen zu.

Du teilst, die anderen schauen

Nach dem Start wird Glotzofon zu einer schmalen Leiste am Bildschirmrand. Die Zuschauer sehen sie nicht.

  • Code, Zuschauer und Verbindung immer im Blick
  • 30 oder 60 fps, Auflösung und Datenrate live umstellen
  • Anderen Monitor oder anderes Fenster teilen, ohne neuen Code
  • Klappt ohne Maus zu einem kleinen Reiter zusammen

Klein, aber kann was

Eine einzige EXE, die alles mitbringt. Für alles, was über Zuschauen hinausgeht, gibt es Fernwartungs-Tools. Glotzofon will nur eins: schnell zeigen.

Nur zuschauen

Niemand kann deine Maus oder Tastatur steuern. Wer zuschaut, sieht nur, was du freigibst.

Auch im Browser

Zuschauen geht ohne App, direkt auf dieser Seite. Praktisch für alle, die nichts installieren wollen.

Grafikkarte kodiert

Nur lizenzfreie Codecs: AV1 per Grafikkarte (NVIDIA RTX 40/50, Intel Arc, neuere AMD), sonst VP9. Scharf bis 4K.

Mehrere Zuschauer

Ein Code für alle. Auf Wunsch immer derselbe feste Code, den sich deine Freunde merken können.

Zeigen-Ping & Reaktionen

Rechtsklick ins Bild, und beim Teilenden erscheint genau dort ein Kreis. Dazu 👍, „Größer bitte“ oder „Ton fehlt“.

Mehrere Wege

Über Code im Internet, direkt per IP-Adresse im Heimnetz oder auf der LAN-Party (ganz ohne Server), oder mit eigenem Server.

Zuschauen wie am Fernseher

Code eintippen, verbinden, zurücklehnen.

  • Vollbild per Doppelklick oder F11
  • Zoom und Verschieben mit Mausrad und Ziehen
  • Verbindungsampel mit Ping und Paketverlust
  • Bedienelemente verschwinden, wenn die Maus ruht

Einstellen, wenn du willst

Die Standardwerte passen meistens. Wer mag, dreht an allem.

  • Modus Scharf (30 fps) oder Flüssig (60 fps)
  • Höchste Auflösung, Datenrate, Codec und Grafikkarte
  • Leiste, Infobereich oder Fenster beim Teilen
  • Hell, Dunkel oder wie Windows, Deutsch oder Englisch

SmartScreen

Meldet Windows „Unbekannter Herausgeber“, auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“ klicken. Die EXE ist nicht signiert, weil ein Zertifikat Geld kostet.

Geprüft

Prüfsumme (SHA-256) und VirusTotal-Ergebnis jeder Version stehen in den Release-Notizen. Updates holt sich die App auf Wunsch selbst.

Privat

Kein Konto, keine Datensammlung. Der Vermittlungsserver sieht nur den Code, nie das Bild. Das läuft direkt und verschlüsselt von PC zu PC.

Wichtig: Wer zuschaut, sieht alles, was im freigegebenen Bildschirm oder Fenster passiert. Vorher prüfen, was geteilt wird, und den Code nur Leuten geben, die du kennst. Alle Details stehen in der Beschreibung auf GitHub.

Über den Namen

Glotzofon steht wirklich im Duden: So nannte man um 1960 scherzhaft den Fernseher, aus glotzen und -fon wie beim Grammofon. Damals saß die ganze Familie vor dem Glotzofon. Heute ist es dein Bildschirm, der für ein paar Minuten zum Fernseher für deine Freunde wird.

Und Xviews? X steht für das Unbekannte, views fürs Sehen. Hier ist es das, was du gerade auf dem Bildschirm hast und deinen Leuten unbedingt zeigen willst.
