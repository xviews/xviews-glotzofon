Was geht ins Internet?

  • Vermittlungsserver (0.peerjs.com oder dein eigener): nur beim Teilen/Zuschauen, um die Verbindung aufzubauen. Er sieht Code und IP-Adressen, nicht das Bild.
  • STUN (Google, Cloudflare): damit beide Seiten ihre öffentliche Adresse erfahren.
  • Das Bild läuft direkt und verschlüsselt (DTLS-SRTP) von PC zu PC – außer du stellst einen eigenen Relay-Server ein.
  • Update-Suche: die öffentliche Release-Seite auf GitHub (einstellbar).

Die App sammelt keine Daten und schickt nichts an mich.

Hinweis

Dieses Tool ist ein privates Projekt. Wer zuschaut, sieht alles, was im freigegebenen Bildschirm oder Fenster passiert – vorher prüfen, was geteilt wird, und den Code nur Leuten geben, die man kennt. Nutzung auf eigene Verantwortung.
